# The Farnsworth Families

The family website: farnsworthfamilies.com

- `index.html`: family home page (events, Farnsworths in Heaven)
- `thanksgiving/`: Thanksgiving 2026 RSVP page and slideshow
- `assets/`: shared look (black, gold and red) and the logo and settings

No family names, photos or RSVP answers are stored in this repo. The pages load them
when someone opens the site from a private Google Apps Script in Cat's account, and
RSVP answers are saved to a Google Sheet only Cat can open.
